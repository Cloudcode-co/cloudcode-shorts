# Build log: leaked-api-key-github

Built a Vietnamese TikTok meme-skit video about accidentally pushing a `.env` file containing an API key to a public GitHub repo at 2 AM, surviving automated scraper bot attacks because the credit card only had 42,000 VND left. The visual design adheres strictly to the meme skit format: a single stylized dark bedroom IT desk photo as the whole background, big animated GIPHY sticker cats acting out each line in the lower half (typing cat, vibing cat facing a cool sunglasses cat, big-eyed shocked cat, dramatic panic screaming cat, and celebratory happy dancing cats), with prominent yellow outlined `MemeCaption` text at the top and punchy `zoomPunch` and `flash` transitions between shots.

During QA inspection across all 10 stills, fixed headline text wrapping and font sizes so all 5 scenes strictly display at most 3 balanced semantic lines without any lone words or overlay collisions, replaced an opaque thumbs-up cat in scene 2 with a clean transparent sunglasses meme cat, upgraded the scene 4 panic reaction to a full-size dramatic screaming cat, and scaled up all meme stickers to fill the lower half while respecting TikTok safe zones.
